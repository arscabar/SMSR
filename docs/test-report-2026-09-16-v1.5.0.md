## 남은 위험

- Codex 로컬 세션 JSONL은 공개 훅 계약이 아니며 형식 변경 시 토큰 표시는 `수집 대기`로 폴백한다.
- 기존 그래프는 토큰 스냅샷이 없어 소급 계산하지 않는다.
- 정적 펫의 실제 다중 모니터 배치와 한국어 IME는 설치 환경 수동 확인이 남았다.
- 설치 파일은 코드 서명되지 않았다.

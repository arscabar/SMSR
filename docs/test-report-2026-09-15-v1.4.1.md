# SMSR v1.4.1 통합 테스트 보고서

## 대상과 판정 기준

- 대상: 날짜 범위 선택, 기간별 프로젝트·워크플로우 목록, Gemini 모델·키 설정, 요약 오류 처리, 노드별 상세, 그래프 중단 상태, 격리 stdio 검사, Windows 설치본
- 판정 기준: Release 빌드, 전체 자체검사, stdio 초기화·도구 목록, 설치 파일 생성과 체크섬 검증이 모두 통과해야 한다.
- 데이터 안전: 자체검사는 임시 SQLite와 임시 DPAPI 키를 사용하고 실제 사용자 데이터와 API 키를 수정하지 않는다.

## 남은 위험

- 실제 WPF 화면의 긴 제목 말줄임과 밝은·어두운 테마 색 대비는 설치 환경에서 확인해야 한다.
- 실제 Gemini 호출 성공 여부는 선택 모델의 계정별 할당량에 영향을 받는다.
- 설치 파일은 코드 서명되지 않았다.
- 클라이언트 프로세스가 강제 종료되어 최종 이벤트를 전송하지 못하면 진행 상태가 남을 수 있다.

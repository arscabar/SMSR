# P2 · Graphify 승인 범위 구현·검증 — 2026-09-30

## 범위와 판정

사용자는 컴파일러 수준 대신 Graphify 기준을 선택했고, 남은 색인·탐색·검증 보강을 승인했다. 기능 구현·자동 검사·설치 실행본 반영·실제 브라우저·재시작 검증을 완료했다. 별도 PC 설치와 사용자 출시 수용까지 완료했다는 뜻은 아니다.

원문 질문 로그 제외, 전역 Git 훅 미적용, 명시적 파일/프로젝트 참조만 저장소 결합, SQLite 원본 유지 결정을 보존했다. Graphify 0.9.70 리비전 `4c21b15e9beeba5faa6871ad7dd188571a6fbb84`의 원본 56모듈·라이선스/NOTICE는 수정하지 않았다. 새 라이브러리·SDK·Graphify 서버나 훅은 추가하지 않았다.

캐시는 JavaScript/TypeScript 계열을 제외한 **원본에서 캐시를 사용하는 추출 경로**에 적용된다. 파일 변경 시 범위 전체의 이름 해소는 다시 수행한다. 구문 복구·미해소를 확정 관계로 꾸미지 않는다. 원본과 일치한다는 검사는 원본의 오탐·누락까지 해결했다는 인증이 아니다.

MCP: `get_graph_relations`, `trace_graph_path`, `get_graph_affected`, `explain_graph_node`, `get_graph_issues`. HTTP: `/api/graph/relations`, `/trace`, `/affected`, `/explain`, `/issues` (`/api/graph` 기준). 기존 도구와 API 계약은 보존한다.

## 사용 순서

1. `찾기`에서 범위를 색인하고 파일·심벌을 검색한다.
2. 연결 패널에서 방향/종류를 선택하고 이전·다음으로 모든 페이지를 확인한다.
3. `경로 시작` → 도착 항목 선택 → `여기까지 경로`로 단계별 근거를 본다.
4. 선택 항목의 `영향 보기`로 직접/간접 연결을 본다. 필요한 경우에만 추론을 포함한다.
5. `분석 근거`·`색인 진단`을 펼쳐 원문 변경·미해소·누락 가능성을 확인한다.

색인이 갱신되면 관계 페이지는 다시 선택해야 한다. 각 경로/영향 조회는 하나의 리비전을 사용한다. 경로 없음과 조회 상한 절단을 구분하며 저장된 정적 관계는 실행 순서·변경 안전성 보장이 아니다.

현재 합의된 경로/영향 p95 ≤2초 기준을 충족하므로 **SQLite를 유지**한다. Kuzu는 읽기 Cypher를 위한 임시 투영이며 원본 DB를 대체하지 않는다. 별도 DB의 우월성을 실측한 결과는 아니다. 기준 초과가 재현되면 동일 데이터/정답/자원 조건에서 대체 DB를 비교한다.

추론 포함 선택을 보완한 최종 AO3 재검사도 통과했다. 같은 80회/동시성8에서 p95 916.34ms·최대949.80ms, Cypher 1,282.70ms·호스트 최대 약328MiB, 200본문 냉11.47초·온3.72초였다. 원본: `artifacts/p2-inferred-load-ao3.json`. 앞 표는 최초 측정 이력이며 두 측정을 다회 통계로 합산하지 않는다.

한계: 각 검사는 이 PC의 단일 실행 측정이다. 실제 혼합 조회는 서비스/SQLite 시간이며 HTTP/화면 시간과 다르다. 동시 색인은 무변경 경로이고 변경 파일의 경쟁 쓰기는 기존 회귀 검사로 별도 확인한다. 메모리는 호스트만 측정하며 Python/Kuzu/임베딩 자식 합산은 아니다. 본문 표본 200개는 실제 모든 저장소 검색 품질/성능을 대표하지 않는다. 본문 캐시 재사용에도 모델 실행 지연이 남으며 2초 조회 기준 충족으로 간주하지 않는다. WPF 큐는 빈 작업 응답이며 실제 IME·렌더링 검사가 아니다.

측정 원본: `artifacts/p2-large-query-20260930.json`, `p2-index-responsiveness-20260930.json`, `p2-project-load-smsr.json`, `p2-project-load-ao3.json` (모두 `artifacts/` 기준).

## 상한·데이터 보호

- 스캐너 10,000경로; 텍스트 파일당 2,000,000바이트; 변환 코드/설정 전체 128MiB.
- 임시 배치당 최대 8파일·JSON 32MiB; 직렬화 합계 512MiB; 제어 요청 JSON 32MiB. 원본 해시와 변환 입력 해시를 검증한다.
- 코드 결과 64MiB·작업기 5분; 다른 분석은 출력 16MiB·2분. 초과/손상/해시 변경/실행 실패는 이전 색인을 보존한다.
- 영구 AST 캐시 항목당 최대16MiB. 원문/이름이 포함될 수 있어 DPAPI로 암호화하며 평문 영구 fallback은 없다. 버전별 오래된 네임스페이스는 자동 총량 회수하지 않는다.
- 임시 분석 사본은 기존 추출기 요구로 평문이지만 작업 후 삭제한다. 원문·질문은 SQLite에 저장하지 않는다. 본문 벡터 캐시는 해시/벡터만 저장한다. 비밀 패턴 제외는 DLP 전체 판정이 아니다.
- 관계 페이지 API 최대100·offset 최대100만, 화면20. 경로/영향은 깊이 최대8·탐색/출력 제한을 알린다. Cypher는 허용된 읽기·200행·5만노드/20만관계; 메타데이터 벡터1만노드·본문1만조각 한도를 유지한다.

## 제외·수동 수용

컴파일러급 전 언어 타입/별칭/오버로드·동적 호출 보장, 정밀 함수 간 PDG/taint, 원문 질문 로그, 전역 Git 훅 실제 설치, 운영 DB 교체는 이번 완료 범위에 넣지 않는다. 기존 선택형 심층 분석기와 기본 그래프의 자동 병합, 미디어 내용 인식도 제공하지 않는다. 에이전트 추론 강도 수집은 별도 문제다.

별도 PC 설치·전체 스크린리더·한국어 IME·다중 모니터와 사용자 최종 출시 수용은 자동 검사로 대체하지 않는다. 근거를 추가할 때는 표본·언어·리비전을 명시한다.

## 최종 운영 검증

- 실행 중인 앱 경로에 검증 DLL·런타임·웹 자산을 반영하고 SHA-256을 대조했다. 실행 경로에 재빌드하지 않았으며 해당 경로의 앱/브리지만 재시작했다. 서버는 `127.0.0.1:49783`에서 ready다.
- 설치 실행본의 일반·추적·정적·고급 회귀와 동일 DLL의 전체 그래프 회귀가 실제 ExitCode 0이다. 원본 56모듈 SHA-256 불일치 0, SQLite 무결성·외래키와 운영 사본 복원 대조를 통과했다.
- 실제 AO3 리비전6에서 `FindElement` → `FindChildNode`의 호출 경로·129줄 근거, 역방향 영향·원문 상태·파일14진단/프로젝트15,342진단 페이지를 확인했다. 진단은 남은 정적 분석 한계이며 모두 해소했다고 판정하지 않는다.
- 실제 `Instruction.cs`에 들어오는 `CALLS` 1,333건을 67페이지로 표시했다. 2페이지 이동과 MCP의 마지막 페이지13개를 대조했다. SVG가 길어져도 선택 중심이 처음 화면에 보이도록 스크롤 위치를 맞췄다.
- 추론 경로가 공통 필터에서 잘못 제외되는 문제를 수정했다. 실제 `ProjectModel.cs` → `Enums.cs` 490줄 관계는 기본 조회에서 제외되고, 추론 포함 시 HTTP/MCP 모두 1단계·`INFERRED` 근거로 나온다. 모호/미해소는 여전히 경로에 넣지 않는다. 문서의 명시 링크·파일까지만 해소된 관계와 구문에서 읽은 근거를 추론과 구분한다.
- 오래 캐시된 ES 모듈이 새 export를 못 찾는 오류를 재현하고 공통 `/assets`의 `Cache-Control: no-store` 및 변경 의존 모듈 키를 반영했다. 실제 브라우저를 새로고침해 검색·경로·영향·진단·페이지가 다시 동작하고 새로운 모듈 오류가 없음을 확인했다.
- 복구 자료: `artifacts/pre-p2-final-20260930-2042/`, 설치 폴더의 `.pre-p2-final-20260930-2042`, `.pre-p2-inferred-20260930-2102`, `.pre-p2-web-cache-20260930-2110` DLL. DB 사본/독립 복원은 `%LocalAppData%/SMSR/verification-backups/20260930-114002-561298/`에 보존했다. 이후 사용자 변경을 비교한 뒤 필요한 파일만 복원한다.

## 재현

```powershell
dotnet build src/SMSR.App/SMSR.App.csproj -c Release -o artifacts/p2-final-validation --nologo -p:CopyRetryCount=0
```

빌드 앱의 `--graph-self-test`, `--graph-static-self-test`, `--graph-advanced-self-test`, `--graph-benchmark`, `--graph-responsiveness-self-test`, `--graph-code-project-self-test <저장소 경로>`를 Windows 일반 사용자 세션에서 실행한다. WPF 실행은 `Start-Process -PassThru -Wait -WindowStyle Hidden`으로 **실제 ExitCode**를 확인한다. Python `test_graphify_{index,cache,batches,protocol,relations,expanded}.py` 및 Node `scripts/test_graph_explorer{,_labels,_relations}.mjs`를 실행한다. 원본 대조 검사는 기존 Graphify가 설치된 별도 Python 경로를 인자로 받는다.

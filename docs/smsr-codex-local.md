# SMSR Codex 로컬 추적

SMSR은 에이전트를 호출하지 않는 수동 수신기다. 연결된 Codex 메인 에이전트와 하위 에이전트가 각자의 상태를 SMSR MCP로 전송한다.

## 기본 MCP 연결

1. SMSR을 실행하고 로컬 서버와 Codex OAuth 연결을 완료한다.
2. Codex를 완전히 재시작한다.
3. 새 작업에서 `/mcp`를 열어 `smsr` 도구가 표시되는지 확인한다.

MCP 초기화 지침만으로 계획과 상태 추적이 동작한다. 별도 플러그인, 마켓플레이스, Node.js, npm, `codex` CLI가 필요하지 않다.

## 선택형 저장소 로컬 기능

- `.codex/hooks.json`: 세션·turn·하위 에이전트 시작/종료를 연결된 `smsr` MCP 도구로 전송한다.
- `.agents/skills/smsr-tracking/SKILL.md`: 계획, heartbeat, 재시도, 다음 작업과 산출물을 각 에이전트가 직접 보내도록 안내한다.

Codex에서 이 저장소를 신뢰한 뒤 `/hooks`를 열어 훅 정의를 검토하고 신뢰한다. 변경된 훅은 해시가 달라지므로 다시 검토해야 한다. 훅은 SMSR이나 MCP 연결이 없을 때 Codex 작업을 차단하지 않는다.

다른 저장소에서 자동 lifecycle 기록도 사용하려면 두 로컬 디렉터리를 대상 저장소의 같은 위치로 복사한다. 기존 `hooks.json`이 있다면 `hooks` 항목을 병합한다. 새 컴퓨터에서는 SMSR 설치와 OAuth 연결을 다시 해야 한다.

모든 설정은 상대적인 저장소 위치와 MCP 서버 이름만 사용하며 사용자명이나 컴퓨터별 절대경로를 포함하지 않는다. OpenAI 공개 플러그인 디렉터리 등록이나 마켓플레이스 설치 과정은 없다.

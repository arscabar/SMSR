# SMSR Codex 자동 추적

SMSR은 에이전트를 호출하지 않는 수동 수신기다. 연결된 Codex 메인 에이전트와 하위 에이전트가 각자의 상태를 SMSR MCP로 전송한다.

## 최초 한 번

1. SMSR을 실행한다.
2. Codex를 다시 열고 OAuth 인증과 사용자 전역 훅을 한 번 신뢰한다.

이후 설정이나 프롬프트 지정은 필요 없다. SMSR은 실행할 때마다 서버·자동 시작·MCP 설정·전역 훅을 확인하고 누락된 SMSR 항목만 복구한다.

## 자동 동작

- 사용자 전역 `~/.codex/hooks.json`의 lifecycle 훅이 세션·turn·하위 에이전트 시작/종료를 전송한다.
- `UserPromptSubmit` 명령 훅이 프로젝트 폴더명과 세션 ID를 추가 개발자 컨텍스트로 제공한다.
- 실질적인 작업은 에이전트가 `save_plan`, `record_heartbeat`, `record_event`를 자동 호출한다.
- 단순 답변은 계획을 만들지 않고 lifecycle만 기록한다.

훅 명령은 사용자 프롬프트 원문을 출력하거나 SMSR에 저장하지 않는다. 비밀, 원시 명령과 모든 도구 호출도 추적하지 않는다. SMSR이나 MCP 연결이 없으면 훅 오류는 Codex 작업을 차단하지 않는다.

## 다른 컴퓨터

SMSR을 실행하면 그 컴퓨터의 실행 경로로 설정이 자동 생성된다. 최초 OAuth와 전역 훅 신뢰만 다시 수행한다. 공개 플러그인이나 마켓플레이스 설치는 없다.

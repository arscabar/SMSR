WPF MCP 작업 관제 앱 개발 계획서

Windows 전용 로컬 앱으로, AI 에이전트가 MCP로 남긴 작업 이벤트를 저장하고 브라우저 대시보드에서 프로젝트 진행 상황을 확인한다.

1. 범위와 목표

  • WPF + WPF-UI 기반의 가벼운 Windows 앱
  • 앱에서 로컬 웹서버 시작/중지와 프로젝트 관리
  • 에이전트는 MCP로 작업 이벤트만 기록
  • 대시보드는 기본 브라우저에서 표시
  • 요약은 앱 LLM 옵션 또는 호출 에이전트 fallback

제외 범위: 원격 접속, 클라우드 동기화, 다중 사용자 권한, 에이전트 실행/중단 제어, WebView 내장 대시보드.

2. 확정된 제품 방향

4. 주요 기능

WPF 앱

  • 프로젝트 선택 시 기본 브라우저로 대시보드 열기

7. 요약과 Export

앱 설정에서 LLM 요약이 켜져 있고 API 키가 있으면 앱이 요약한다. 설정이 없으면 MCP가 요약 재료를 반환하고 호출한 에이전트가 save_summary로 저장한다.

Export는 HTML, Markdown, JSON, ZIP을 지원한다. ZIP에는 dashboard.html, workflow-state.json, events.jsonl, summary.md, artifacts-index.json을 포함한다.

8. 보안 규칙

  • 서버는 127.0.0.1에만 bind
  • local token으로 MCP 호출 검증
  • API key는 DPAPI 또는 Credential Manager에 저장
  • artifact 경로는 프로젝트 root 밖으로 나갈 수 없음
  • HTML 렌더링은 escaping 또는 textContent 사용

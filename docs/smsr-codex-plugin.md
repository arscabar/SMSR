# smsr-codex 플러그인

`smsr-codex`는 SMSR이 에이전트를 호출하는 플러그인이 아니다. 연결된 Codex 메인 에이전트와 하위 에이전트가 각자의 상태를 SMSR MCP로 전송한다.

## Codex 데스크톱 앱 설치

1. SMSR을 실행하고 로컬 서버 및 Codex OAuth 연결을 완료한다.
2. Codex 플러그인 화면에서 저장소의 `.agents/plugins/marketplace.json`을 로컬 마켓플레이스로 연다.
3. `smsr-codex`를 설치·활성화한다.
4. `/hooks`에서 플러그인의 `mcp_tool` 훅 정의를 검토하고 신뢰한다.
5. 새 Codex 작업을 열어 변경된 스킬과 훅을 로드한다.

플러그인 실행에는 Node.js, npm, 별도 `codex` CLI가 필요하지 않다. 로컬 마켓플레이스 경로는 설치 환경마다 저장소 위치에 맞게 선택하며, 플러그인 소스나 훅에는 특정 사용자·컴퓨터의 절대 경로가 없다.

## 동작 범위

- 훅: 세션 및 하위 에이전트 시작·종료 heartbeat를 연결된 `smsr` MCP 도구로 전송한다.
- 스킬: 계획, 진행률, 재시도, 다음 작업, 산출물을 각 에이전트가 직접 보내도록 지시한다.
- 장애 처리: SMSR이 실행 중이 아니거나 MCP가 연결되지 않은 경우 훅 실패는 Codex 작업 자체를 차단하지 않는다.

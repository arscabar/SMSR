2. 사용 순서

  1. 새 소스 앱의 찾기에서 프로젝트 전체/선택 폴더를 색인합니다. 정적 코드·명시 문서 관계는 같이 분석됩니다.
  2. 이미지·음원·영상을 선택하고 내용 분석 · 영역과 시간 근거를 펼쳐 로컬 분석 확인을 누릅니다. ANALYSIS_PENDING이면 안내 후 다시 확인합니다. 실패는 도구/모델/입력 제한을 확인하고 명시 재시도합니다.
  3. OCR 영역·시간 링크로 현재 원문 위치를 확인합니다. PDF는 페이지를 안전한 래스터로 보여주며 PDF 스크립트를 실행하지 않습니다.
  4. 의미 관계는 read_graph_media 또는 read_graph_document → 호스트 추출 → submit_graph_document_semantics → get_graph_document_semantics로 검증·저장합니다. 원문/지문/인용이 달라지면 재분석합니다.
  5. 변경 감시 · 보고서 · 내보내기에서 감시 상태 확인 후 사용자가 켜거나 끕니다. 보고서는 저장 결과를 조회합니다. 전체 내보내기와 선택 항목 주변 내보내기는 범위가 다릅니다.
  6. 다운로드한 HTML은 독립 탐색용, GraphML은 교환용, SVG는 정적 시각 자료입니다. Wiki/Obsidian은 새 ZIP이므로 기존 사용자 노트를 직접 덮어쓰지 않습니다. 공유 전 경로·라벨·짧은 근거 인용의 공개 범위를 확인하세요.

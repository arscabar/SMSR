# SMSR v1.7.0

## 변경 사항

- 작업 이력의 배경·진행 방식·최종 결과와 그래프 UI를 개선했습니다.
- 코드·문서 찾기에 파일 종류 필터, 페이지 이동, 관계 표시 확장과 C# 파일 간 정적 호출·명시적 프로젝트 참조 색인을 추가했습니다.
- 문서 제목을 찾기의 별도 결과에서 제외하고, 색인된 이미지·영상·음원을 브라우저에서 바로 확인할 수 있게 했습니다.
- 고급 분석, 증분 색인, 피드백, 검증 누락, 관계 비교 등 현재 구현 범위와 제한은 README에 정리했습니다.

## 설치

`SMSR-Setup-1.7.0.0-win-x64.exe`를 실행합니다. 기존 사용자 설정과 SQLite 작업 기록은 유지됩니다.

## 알려진 제한

- 설치 파일은 코드 서명되지 않았습니다.
- C# 기본 색인은 파일 간 호출만 표시하고 호출 횟수·함수 단위 경로·다른 언어의 정적 관계는 아직 통합하지 않습니다.
- 관계 그래프는 방향별 최대 100개까지만 조회하며, 미디어 재생은 브라우저 코덱 지원과 파일 크기 제한을 따릅니다.

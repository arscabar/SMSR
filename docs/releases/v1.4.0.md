# SMSR v1.4.0

한 달짜리 통합 작업 그리드와 Gemini 우선 일자별 LLM 요약을 추가한 Windows 기능 릴리스입니다.

## 주요 변경사항

- 첫 탭의 중복 `현재 상태` 영역과 상태 새로고침을 제거하고 작업 탐색에 집중
- 한 번에 한 달만 표시하는 7열 날짜 그리드와 날짜별 그래프·일일 기록 수
- 기존 `이벤트 · 요약` 탭을 최근 이벤트 없는 `작업 요약` 전용 탭으로 개편
- `금일 작업 요약`과 `그리드 선택일자 전체 요약`을 분리해 모든 프로젝트 기록을 날짜별로 통합
- 설정에서 Gemini API 키 저장·연결 확인·삭제 지원
- API 키를 `%LocalAppData%\SMSR\gemini-api-key.bin`에 Windows 현재 사용자 DPAPI로 암호화
- `gemini-2.5-flash` 요약을 우선 사용하고 키 미설정 또는 호출 실패 시에만 Codex 요청으로 전환
- Codex 대체 요약용 `get_daily_summary_request`, `save_daily_summary_result` 추가로 MCP 도구 총 12개 제공
- Codex CLI·Node.js·npm 없이 `codex://` 새 작업과 기존 SMSR stdio MCP로 결과 회수

## 설치

배포 파일은 `SMSR-Setup-1.4.0.0-win-x64.exe` 하나입니다. 기존 설치 위에 실행하면 사용자 설정, Gemini 키, SQLite 이력과 내보낸 파일을 보존하면서 업그레이드합니다. 대상 PC에 .NET SDK, Node.js, npm 또는 별도 Codex CLI가 필요하지 않습니다.

설치 후 Codex를 한 번 완전히 다시 시작해야 새 요약 도구를 포함한 12개 MCP 도구가 반영됩니다. 기존 전역 훅 신뢰가 유지되면 브라우저 인증은 필요하지 않습니다.

## 검증

- Release 빌드 경고 0, 오류 0
- config·tracking·update·OAuth·전체 자체 검사 통과
- DPAPI Gemini 키 저장·복호화·삭제와 가짜 HTTP Gemini 요청·응답 계약 통과
- Codex 요약 요청 생성·조회·결과 저장의 실제 HTTP MCP 왕복 통과
- stdio protocol `2025-11-25`, MCP 도구 12개 확인
- 신규 C# 파일 포맷과 전체 diff 검사 통과

정확한 설치 파일 해시는 릴리스에 함께 첨부된 같은 이름의 `.sha256` 파일에서 확인할 수 있습니다.

## 알려진 제한

- 실제 Gemini API 호출은 사용자가 자신의 키를 저장한 환경에서 연결 확인해야 합니다.
- Codex Desktop 딥링크는 프롬프트를 채워 열지만 자동 전송하지 않으므로 사용자가 전송을 한 번 눌러야 합니다.
- Codex 대체 요약 요청은 SMSR 서버 메모리에 보관되므로 결과가 돌아오기 전에 서버를 종료하면 다시 요청해야 합니다.
- 설치 파일은 코드 서명되지 않아 다른 PC에서 Windows SmartScreen 경고가 표시될 수 있습니다.

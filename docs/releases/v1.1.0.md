# SMSR v1.1.0

Codex 작업 그래프의 연결 안정성, 실시간 추적, 완료 상태 표현을 개선한 Windows 릴리즈입니다.

## 주요 변경사항

- 브라우저 인증 없이 동작하는 로컬 stdio MCP 연결과 Codex 시작 시 SMSR 서버 자동 복구
- 그래프가 활성화된 동안 지원되는 Codex 활동을 `activity.jsonl`로 기록하고 SSE로 즉시 갱신
- 현재 작업 노드 하나만 강조하고 흐름·그래프·상세 패널의 스크롤 위치 유지
- 날짜·프로젝트·대표 작업명이 포함된 읽기 쉬운 workflow ID 자동 생성
- 진행 중인 계획의 노드 추가·순서 변경과 기존 진행률 보존
- `SUCCESS(100%)` 노드 재개·변경·하위 작업 추가 및 완료 그래프 변경 차단
- 기존 UUID workflow를 최상위 작업 제목과 함께 표시
- JSON·HTML 필드 기반 자체 검사와 단계별 실패 진단 보강

## 설치

`SMSR-Setup-1.1.0.0-win-x64.exe`를 실행합니다. 현재 Windows 사용자 범위에 설치되며 별도 .NET SDK, Node.js 또는 Codex CLI가 필요하지 않습니다.

기존 설치 위에 실행하면 설정과 SQLite 작업 이력을 유지하면서 업그레이드됩니다. 처음 설치한 PC에서는 SMSR 실행 후 Codex를 한 번 다시 열고 전역 훅 신뢰를 승인해야 합니다.

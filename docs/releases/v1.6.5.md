# SMSR v1.6.5

## 변경 사항

- 목표 토큰 호버를 신규 입력·캐시 입력·출력 카드로 표시합니다.
- 그래프 추정 토큰 호버를 입력·출력 카드로 표시합니다.
- 상단에서 진행률과 중복되는 완료·정체·확인·실패 숫자 칩을 제거했습니다.
- 에이전트 이름은 카드 안에서 한 줄 말줄임으로 표시하고 상태 배지는 오른쪽에 고정했습니다.
- 상단 연결·토큰·진행률 칩을 한 줄로 유지합니다.
- 완료된 펫을 더블클릭하면 완료 확인 처리와 SMSR 창 열기를 함께 수행합니다.
- 목표 작업 토큰을 목표 시작 기준 증분으로 계산하고 캐시 입력을 별도로 수집합니다.
- 그래프 추정 토큰은 SMSR 계획·상태 기록 요청과 응답만 집계합니다.
- 검증·테스트 역할의 그래프 노드를 노란색으로 구분합니다.
- README에서 에이전트·작업 흐름·상세·토큰 분류가 포함된 샘플 그래프를 확인할 수 있습니다.
- 자동 갱신 요청이 지연돼도 8초 뒤 복구합니다. 노드 선택 시 백그라운드 갱신을 취소해 사용자 선택을 우선하고 반영·이동 상태를 연결 칩에 표시합니다.

## 설치

`SMSR-Setup-1.6.5.0-win-x64.exe`를 실행합니다. 기존 설정, 그래프 DB, Gemini 키와 펫 미디어는 유지됩니다.

## 알려진 제한

- 설치 파일은 코드 서명되지 않았습니다.
- 기존 토큰 기록에는 캐시 입력 스냅샷이 없으므로 새 기록부터 세부 분류가 표시됩니다.

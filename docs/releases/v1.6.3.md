# SMSR v1.6.3

펫 진행률 구간과 크기를 직접 조정하고, 완료 후 대기 상태를 간결하게 표시하는 릴리스입니다.

## 주요 변경

- 하나의 진행률 막대에서 미디어 경계선을 드래그해 구간을 조정합니다.
- 구간은 0~100%를 빈틈·겹침 없이 유지하며 미디어 추가·삭제 시 다시 균등 분할됩니다.
- 펫 크기 60~180% 설정을 이미지·영상에만 적용합니다.
- 100% 완료 시 펫을 우클릭해 `완료 확인`할 수 있습니다.
- 완료 확인 후 별도 대기 미디어와 IDLE 움직임을 표시하고, 하단 진행률은 숨깁니다.
- 진행 중 하단 표시는 작업 설명 없이 진행률 숫자만 보여 줍니다.
- 펫을 더블클릭하면 숨겨진 SMSR 창을 복원합니다.

## 검증

- Release 빌드 경고 0, 오류 0
- 전체 자체검사와 tracking 자체검사 종료 코드 0
- 설치 후 HTTP health `ready`
- 설치 전후 설정·SQLite DB·Gemini 키 파일 SHA-256 일치
- 설치 버전 `1.6.3.0`, 단일 SMSR 프로세스 확인

## 알려진 제한

- MP4 알파 투명도는 Windows 기본 재생기가 지원하지 않습니다.
- 설치 파일은 코드 서명되지 않았습니다.

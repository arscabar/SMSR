# SMSR v1.4.4

그래프 사용자 요청 이력과 AI 질의 입력을 개선한 Windows 릴리스입니다.

## 주요 변경사항

- 새 그래프의 최초 사용자 요청을 노드 시작 상태 기록에 1~2문장 요약으로 저장
- 활성 그래프에 반영되는 관련 후속 사용자 요청도 해당 새 노드의 시작 이력에 저장
- 프롬프트 원문·비밀·개인정보는 저장하지 않는 기존 보호 정책 유지
- AI 질의 입력의 매 글자 ViewModel 갱신을 제거해 한글 IME 조합 안정화
- 질문 실행 시 빈 값과 최대 1,000자 입력 검증 유지

## 설치

`SMSR-Setup-1.4.4.0-win-x64.exe`로 기존 설치를 업그레이드한 뒤 SMSR과 Codex를 완전히 다시 시작합니다.

## 알려진 제한

- 기존 그래프에 과거 요청 요약을 소급 생성하지 않으며, 설치 후 새 요청부터 적용됩니다.
- 설치 파일은 코드 서명되지 않아 Windows SmartScreen 경고가 표시될 수 있습니다.

# SMSR v1.2.0

여러 프로젝트의 그래프를 날짜로 탐색하고 로컬 기록을 안전하게 정리할 수 있는 Windows 기능 릴리즈입니다.

## 주요 변경사항

- 모든 프로젝트를 한 번에 조회하는 작업 캘린더와 날짜별 최신 작업 자동 전환
- 같은 날짜의 프로젝트·작업·상태·노드 수 목록과 원본 workflow ID 툴팁
- UUID 형태의 이전 ID는 기본 화면에서 숨기고 계획 제목이나 최근 이벤트 요약을 우선 표시
- 다른 프로젝트 이벤트가 와도 현재 선택을 강제로 바꾸지 않고 캘린더만 실시간 갱신
- 같은 Codex 세션에서 A 프로젝트 뒤 B 프로젝트를 추적할 때 활동 JSONL 매핑을 B로 갱신
- 선택 작업·현재 프로젝트·전체 이력 삭제와 실행 전 확인창
- 삭제 시 SQLite, 활동 JSONL, 자동추적 세션 매핑을 함께 정리하고 내보낸 ZIP/HTML과 설정은 보존
- 계획 없는 이벤트·heartbeat를 거부해 새 UUID 전용 그래프가 생기는 순서 오류 방지
- 최근 이벤트에 SMSR 수신 시각과 에이전트가 보고한 산출물 경로 표시

## 설치

`SMSR-Setup-1.2.0.0-win-x64.exe`를 실행합니다. 기존 설치 위에 실행하면 설정과 기존 작업 이력을 유지하면서 업그레이드됩니다. 별도 .NET SDK, Node.js, Codex CLI 또는 브라우저 OAuth 인증은 필요하지 않습니다.

변경된 MCP 지침과 앱 실행 파일을 현재 Codex 작업에 반영하려면 설치 후 Codex를 한 번 완전히 다시 시작합니다.

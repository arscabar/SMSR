# SMSR v1.5.0

작업 상태 판단, 범위 기반 AI 요약·질의, 사용자 등록 펫, 토큰 관제를 함께 제공하는 Windows 릴리스입니다.

## 주요 변경사항

- AI 요약·질의 팝업에서 특정 프로젝트 또는 전체 프로젝트와 오늘·선택 기간을 조합할 수 있습니다.
- 완료 그래프, 자동 갱신, 정체 가능, 차단, 실패를 다른 의미로 표시하고 선택 노드의 활동과 상태 기록만 보여줍니다.
- 10MB 이하 PNG·JPG·BMP 한 장을 펫으로 등록해 선택 그래프의 상태·진행률을 표시하고 트레이에서 숨기거나 다시 표시할 수 있습니다.
- Codex가 보고한 현재 목표 작업 전체와 그래프 연결 이후의 IN/OUT 토큰을 구분해 표시합니다.
- 사용량이 없거나 형식이 지원되지 않으면 추정값 대신 `수집 대기`를 표시합니다.
- 기능 확장 계획서에 v1.5.0 구현 현황과 검색·필터, 인수인계 묶음, 펫 접근성 등 후속 작업을 반영했습니다.

## 알려진 제한과 후속 작업

- 기존 그래프에는 토큰 사용량을 추정해 소급하지 않습니다.
- 토큰 입력은 Codex 로컬 세션 형식을 사용하므로 향후 형식이 바뀌면 `수집 대기`로 안전하게 폴백합니다. 공개 사용량 계약이 생기면 입력부를 교체할 예정입니다.
- 펫 1차 버전은 정적 이미지와 상태별 WPF 움직임을 사용합니다. 크기·투명도·움직임 감소와 스프라이트 애니메이션은 실제 사용성 확인 후 추가합니다.
- 한국어 IME, 다중 모니터 펫 배치, 완료·차단 그래프는 실제 설치 환경에서 추가 수용 검사가 필요합니다.
- 설치 파일은 코드 서명되지 않아 Windows SmartScreen 경고가 표시될 수 있습니다.

# SMSR v1.4.2

작업 그래프의 노드별 이력과 에이전트 표시를 정리한 Windows 안정화 릴리스입니다.

## 주요 변경사항

- 그래프 노드 선택 시 해당 노드의 상태 변경 이력을 최신 한 건이 아닌 개별 카드로 표시
- 다른 노드의 이력이 선택 노드 상세에 섞이지 않도록 DB 조회부터 노드 ID로 필터링
- 선택 노드 상태 카드 최대 50건 제공
- 전체 그래프 화면은 기존처럼 노드별 최신 상태 한 장으로 요약
- `root`, `implementation-validation`, `STALE` 같은 내부값을 `주 에이전트`, `구현 · 검증`, `응답 지연`으로 표시
- 에이전트 카드에 내부 노드 ID 대신 실제 작업 제목을 우선 표시

## 설치

`SMSR-Setup-1.4.2.0-win-x64.exe`로 기존 설치를 업그레이드한 뒤 Codex를 완전히 다시 시작합니다.

설정, DPAPI Gemini 키, SQLite 이력과 내보낸 파일은 보존됩니다.

## 알려진 제한

- 클라이언트가 강제 종료되어 이벤트를 전송하지 못한 작업은 이력 카드가 생성되지 않습니다.
- 설치 파일은 코드 서명되지 않아 Windows SmartScreen 경고가 표시될 수 있습니다.

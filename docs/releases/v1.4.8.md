# SMSR v1.4.8

대시보드 정보 가독성과 중첩 작업 계획을 보강한 Windows 릴리스입니다.

## 주요 변경사항

- 에이전트 카드에서 역할·현재 작업을 우선 표시하고 기술 식별자는 접었다.
- 작업 상세를 상태, 담당·역할, 결과, 접힌 완료 기준, 갱신 시각으로 정리했다.
- `save_plan`의 `children` 입력을 `parentNodeId` 드릴다운 계층으로 자동 전개한다.
- 계획 생성 지침이 독립 추적 가능한 A1·A2 하위 작업을 먼저 만들도록 강화했다.

## 설치

`SMSR-Setup-1.4.8.0-win-x64.exe`로 기존 설치를 업그레이드합니다.

## 알려진 제한

- 하위 작업 제목과 완료 조건은 작업을 수행하는 에이전트가 실제 범위에 맞춰 생성한다.
- 설치 파일은 코드 서명되지 않아 Windows SmartScreen 경고가 표시될 수 있습니다.

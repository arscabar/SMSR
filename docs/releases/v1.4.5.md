# SMSR v1.4.5

Gemini 대체 모델 확인과 AI 질의 한글 입력을 보완한 Windows 릴리스입니다.

## 주요 변경사항

- Gemini 모델이 404·429·503으로 응답하면 사용 가능한 다른 Flash 모델명을 확인창에 표시
- 사용자 동의 시 제안 모델로 현재 요청만 재시도하고 기본 모델 설정은 유지
- 대체 모델을 거절하거나 재시도도 실패하면 기존 Codex 요청 경로 사용
- 별도 투명 WPF `Popup`을 같은 창 내부 모달 오버레이로 교체해 한글 IME 조합 단절 원인 제거
- 질의 텍스트는 포커스를 벗어날 때만 ViewModel에 전달하며 실행 시 1~1,000자 검증 유지

## 설치

`SMSR-Setup-1.4.5.0-win-x64.exe`로 기존 설치를 업그레이드합니다.

## 알려진 제한

- 대체 모델은 API 키에서 조회되는 비 Preview Flash 모델 중 `gemini-2.5-flash`를 우선 제안합니다.
- 설치 파일은 코드 서명되지 않아 Windows SmartScreen 경고가 표시될 수 있습니다.

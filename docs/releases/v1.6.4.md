# SMSR v1.6.4

선택 없음 상태와 Windows 창 전환에서 펫 표시를 자연스럽게 다듬은 패치 릴리스입니다.

## 주요 변경

- 프로젝트 또는 워크플로우 선택이 없으면 펫을 IDLE 상태로 전환하고 진행률을 숨깁니다.
- 이전 완료 그래프 데이터가 잠시 남아도 100%로 표시하지 않습니다.
- 펫에 Windows 도구 창 스타일을 적용해 `Alt+Tab`에서는 제외합니다.
- SMSR 메인 창을 최소화하거나 트레이로 숨겨도 펫은 화면에 유지됩니다.

## 검증

- Release 빌드 경고 0, 오류 0
- 전체 자체검사와 tracking 자체검사 종료 코드 0
- 설치 후 HTTP health `ready`
- 설치 전후 설정·SQLite DB·Gemini 키 파일 SHA-256 일치
- 설치 버전 `1.6.4.0`, 단일 SMSR 프로세스 확인

## 알려진 제한

- MP4 알파 투명도는 Windows 기본 재생기가 지원하지 않습니다.
- 설치 파일은 코드 서명되지 않았습니다.

# SMSR v1.3.0

간단한 작업은 날짜별 일지로, 복잡한 작업은 그래프로 구분하고 앱 자체 업데이트까지 제공하는 Windows 기능 릴리스입니다.

## 주요 변경사항

- 계산, 짧은 검색, 질문, 읽기 전용 확인은 기록하지 않고 실제 프로젝트 파일 변경만 일일 작업으로 기록
- 여러 단계·파일·검증 등 복잡도 신호가 두 개 이상일 때만 선택적으로 그래프 자동 생성
- 설정에서 복잡 작업 자동 그래프를 체크박스로 켜거나 끄는 기능
- 캘린더 날짜별 프로젝트 작업 요약, 변경 파일, 검증 결과, 상태와 연결 그래프 표시
- `record_daily_activity` 추가로 MCP 도구 10개 제공
- 우측 상태 기록을 노드별 최신 카드로 표시하고 개별·전체 접기 지원
- SSE 갱신 뒤에도 그래프·상세 스크롤과 상태 카드 접힘 유지
- 설정의 자동 업데이트 체크박스와 수동 업데이트 확인 버튼
- GitHub 정식 릴리스 설치 파일을 SHA-256 검증한 뒤 무인 업그레이드하고 앱 재실행
- Codex stdio용 `SMSR.Bridge.exe`와 화면용 `SMSR.App.exe` 분리로 브라우저 인증이나 Codex CLI 없이 서버 자동 복구

## 설치

배포 파일은 `SMSR-Setup-1.3.0.0-win-x64.exe` 하나입니다. 기존 설치 위에 실행하면 사용자 설정, SQLite 이력과 내보낸 파일을 보존하면서 업그레이드합니다. 대상 PC에 .NET SDK, Node.js, npm, Codex CLI가 필요하지 않습니다.

설치 폴더에는 화면 앱과 MCP stdio 브리지가 내부 구성요소로 함께 배치됩니다. 사용자가 브리지를 별도로 실행하거나 경로를 입력할 필요는 없습니다. 해당 PC의 실제 설치 위치가 Codex 설정에 자동 반영됩니다.

설치 후 Codex를 한 번 완전히 다시 시작하면 새 도구와 추적 지침이 반영됩니다. 기존 전역 훅 신뢰가 유지되는 경우 추가 브라우저 인증은 없습니다.

## 검증

- Release 빌드 경고 0, 오류 0
- config·tracking·OAuth·전체 자체 검사 통과
- 임시 SQLite에서 일일 기록 생성·정정·날짜 조회·삭제 통과
- 설치본 stdio protocol `2025-11-25`, 도구 10개 확인
- 앱 종료 상태에서 MCP 브리지 호출 시 설치 앱과 `127.0.0.1:49783` 서버 자동 복구 확인
- 실제 설치본 WPF UI Automation으로 캘린더·일일 요약·자동 그래프·자동 업데이트 컨트롤 확인
- 실행 중 대시보드 HTML에서 상태 카드·전체 접기·SSE·스크롤 및 접힘 복원 계약 확인
- 기존 설정 파일을 보존한 무인 업그레이드 확인

정확한 설치 파일 해시는 릴리스에 함께 첨부된 같은 이름의 `.sha256` 파일에서 확인할 수 있습니다.

## 알려진 제한

- 설치 파일은 아직 코드 서명되지 않아 다른 PC에서 Windows SmartScreen 경고가 표시될 수 있습니다.
- GitHub 최신 릴리스 확인에는 인터넷 연결이 필요합니다. 확인 실패는 앱 실행을 막지 않으며 설정 화면에만 표시됩니다.
- 자동 기록 여부와 복잡도는 에이전트 지침에 따라 판단됩니다. 사용자가 그래프를 명시적으로 요청하면 자동 복잡도 설정보다 우선합니다.

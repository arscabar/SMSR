# SMSR v1.1.1

완료된 그래프와 실제 에이전트 후속 작업의 상태가 어긋나지 않도록 계획 갱신 계약을 보완한 Windows 패치 릴리즈입니다.

## 주요 변경사항

- 같은 요청의 보완·수정·검증·문서·커밋·배포 작업을 완료된 기존 그래프에 연결된 새 노드로 추가
- 기존 `SUCCESS(100%)` 노드의 상태·정의·계층은 그대로 보호
- 관련 후속 노드 추가 시 workflow를 `TERMINAL`에서 `ACTIVE`로 전환하고 전체 진행률을 다시 계산
- 연결되지 않은 별도 작업은 기존 완료 그래프에 섞지 않고 새 그래프로 생성하도록 안내
- 후속 작업 실행 전에 `save_plan`과 즉시 `IN_PROGRESS` 이벤트를 보내도록 MCP·Codex 훅·스킬 지침 보강
- 완료 3개 뒤 후속 노드를 추가해 `완료 3 / 4`로 표시되는 회귀 시나리오 추가

## 설치

`SMSR-Setup-1.1.1.0-win-x64.exe`를 실행합니다. 기존 설치 위에 실행하면 설정과 SQLite 작업 이력을 유지하면서 업그레이드됩니다. 별도 .NET SDK, Node.js, Codex CLI 또는 브라우저 OAuth 인증은 필요하지 않습니다.

변경된 MCP와 전역 훅 지침을 현재 Codex 작업에 반영하려면 설치 후 Codex를 한 번 완전히 다시 시작합니다. 훅 정의 자체는 바뀌지 않았으므로 이미 신뢰한 PC에서는 보통 다시 승인할 필요가 없습니다.

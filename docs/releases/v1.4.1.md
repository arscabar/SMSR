# SMSR v1.4.1

작업 현황의 날짜 탐색과 Gemini 요약 설정을 정리한 Windows 기능·안정화 릴리스입니다.

## 주요 변경사항

- 달력 첫 클릭은 단일 날짜, 두 번째 클릭은 시작일~종료일 기간으로 선택
- 오늘 배지를 선택 강조와 분리하고 기간 시작·중간·종료 표시를 구분
- 선택 기간에 활동한 프로젝트와 워크플로우만 상단 목록에 표시
- 여러 날짜에 걸친 동일 워크플로우를 날짜별로 조회하되 선택 목록에서는 한 번만 표시
- 워크플로우 선택 상자의 펼친 목록과 닫힌 영역 모두 작업 제목만 표시
- 작업 요약을 첫 화면으로 통합하고 중복 상세 그래프·일일 기록 목록 제거
- Gemini 모델 조회·사용자 선택·저장을 지원하고 기본값을 `gemini-3.8-flash`로 변경
- 저장된 Gemini 키를 DPAPI로 보호한 채 마스킹해 불러오고 눈 버튼으로 표시·숨김
- Gemini 실패 원인을 `미연결`로 덮지 않고 모델·할당량·응답 오류로 표시
- 작업 현황 휠 스크롤 반응 개선
- 그래프 노드 선택 시 작업 상세의 활동·상태 기록을 해당 노드로 한정
- 최종 응답 전 남은 진행 노드를 재확인하고 성공·실패·차단·중단 상태로 종결하도록 추적 계약 강화
- 미완료 상태로 다음 요청으로 넘어가거나 사용자가 중단한 그래프에 `CANCELLED(중단)` 표시 추가
- stdio 릴리스 검사를 격리해 실행 중 SMSR 종료와 테스트용 백그라운드 프로세스 생성을 방지

## 설치

`SMSR-Setup-1.4.1.0-win-x64.exe`를 실행하면 기존 설정, DPAPI Gemini 키, SQLite 이력과 내보낸 파일을 보존하면서 업그레이드합니다. 대상 PC에 .NET SDK, Node.js, npm 또는 별도 Codex CLI는 필요하지 않습니다.

설치 후 Codex를 완전히 다시 시작해야 설치본의 stdio 브리지와 12개 MCP 도구가 반영됩니다.

## 알려진 제한

- 실제 Gemini 사용 가능 모델과 할당량은 API 키 계정 정책에 따라 달라집니다.
- 설치 파일은 코드 서명되지 않아 Windows SmartScreen 경고가 표시될 수 있습니다.
- Codex 대체 요약 작업은 보안상 자동 전송되지 않으므로 사용자가 전송을 한 번 눌러야 합니다.

# SMSR v1.6.2

선택 그래프를 더 명확하게 관찰하고, 진행 중인 Codex 작업에 대시보드에서 바로 지시하며, 진행률별 펫 미디어를 간단히 구성하는 릴리스입니다.

## 주요 변경

- 펫 미디어에 PNG, JPG, APNG, GIF, MP4를 여러 개 등록할 수 있습니다.
- 등록 개수에 따라 0~100% 진행률 영역을 겹침 없이 자동 균등 분할하고, 추가·삭제 시 즉시 재배치합니다.
- 투명 PNG·APNG·GIF와 반복 MP4 재생을 지원합니다.
- 활성 heartbeat가 있는 진행 노드에만 `이어 진행`, `더 빠르게`, `재설계` 버튼을 표시합니다.
- 버튼 지시는 다음 `record_event` 또는 `record_heartbeat` 응답으로 현재 Codex 작업에 한 번 전달됩니다.
- AI 요약·질의의 프로젝트 목록은 선택 날짜 또는 기간에 기록이 있는 프로젝트만 표시합니다.
- 요약 범위 선택값은 객체 문자열 대신 프로젝트명만 표시하며 `Esc`로 팝업을 닫을 수 있습니다.

## 검증

- Release 빌드 경고 0, 오류 0
- 전체 자체검사와 tracking 자체검사 종료 코드 0
- 설치 후 HTTP health `ready`
- 설치 전후 설정과 SQLite DB SHA-256 일치
- 설치 버전 `1.6.2.0`, 단일 SMSR 프로세스 확인

## 알려진 제한

- 실행 중인 긴 외부 명령은 대시보드 지시로 즉시 중단되지 않으며 다음 상태 기록 또는 heartbeat에서 지시를 받습니다.
- MP4 알파 투명도는 Windows 기본 재생기가 지원하지 않습니다.
- 설치 파일은 코드 서명되지 않았습니다.

# SMSR v1.4.3

선택한 프로젝트와 날짜 자료의 AI 요약·질의를 한 팝업에 모은 Windows 릴리스입니다.

## 주요 변경사항

- 작업 캘린더 본문에서는 긴 요약 결과를 제거하고 `AI 요약·질의 열기` 버튼만 표시
- 팝업에서 오늘 또는 선택 기간의 프로젝트 작업 요약 생성
- 같은 프로젝트·기간 기록을 근거로 작업 이유와 필요성 등을 자유롭게 질문
- 질문은 최대 1,000자로 제한하고 기록에 근거가 없을 때 확인 불가로 답하도록 Gemini·Codex 프롬프트 강화
- 요약과 질의 모두 설정된 Gemini 모델을 사용하고, 실패하거나 키가 없으면 기존 Codex 요청 경로 사용

## 설치

`SMSR-Setup-1.4.3.0-win-x64.exe`로 기존 설치를 업그레이드한 뒤 Codex를 완전히 다시 시작합니다.

설정, DPAPI Gemini 키, SQLite 이력과 내보낸 파일은 보존됩니다.

## 알려진 제한

- 답변은 선택한 기간에 SMSR가 기록한 그래프·일일 작업 내용에 한정됩니다.
- 설치 파일은 코드 서명되지 않아 Windows SmartScreen 경고가 표시될 수 있습니다.

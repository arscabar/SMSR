# SMSR v1.4.7

진행 중인 도구 작업을 실시간으로 표시하는 Windows 릴리스입니다.

## 주요 변경사항

- Codex `PreToolUse` 훅을 등록해 도구 실행 전에 `작업 시작` 활동 기록
- 기존 추적 세션의 활성 하위 노드에 시작·완료 활동 자동 연결
- 노드 ID 대신 작업 제목, 영문 이벤트 대신 한국어 활동명 표시
- 완료되지 않은 도구 활동에 진행 상태와 초 단위 경과 시간 표시
- SSE 연결·재연결 상태를 대시보드 상단에 표시

## 설치

`SMSR-Setup-1.4.7.0-win-x64.exe`로 기존 설치를 업그레이드합니다.

## 알려진 제한

- 그래프의 노드 상태 변경은 정확성을 위해 기존 `record_event`를 사용합니다.
- 설치 파일은 코드 서명되지 않아 Windows SmartScreen 경고가 표시될 수 있습니다.

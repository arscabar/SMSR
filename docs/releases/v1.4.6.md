# SMSR v1.4.6

Gemini 대체 모델 선택 오류를 수정한 Windows 릴리스입니다.

## 주요 변경사항

- 사용 불가능한 `gemini-2.5-flash` 고정 우선순위 제거
- API 키로 조회된 비 Preview Flash 모델 중 현재 모델을 제외한 최신 버전을 제안
- 같은 버전에서는 일반 Flash를 Flash Lite보다 우선 선택

## 설치

`SMSR-Setup-1.4.6.0-win-x64.exe`로 기존 설치를 업그레이드합니다.

## 알려진 제한

- 제안된 모델도 API에서 거부되면 기존 Codex 요청 경로로 전환됩니다.
- 설치 파일은 코드 서명되지 않아 Windows SmartScreen 경고가 표시될 수 있습니다.

# Python 컴파일러 근거 예제

SMSR 프로젝트를 색인하고 `/graph/advanced?projectId=SMSR`에서 `저장소 상대 파일 경로`에 `samples/graph-python/scopes.py`를 입력한다. `분석·저장` 뒤 `Python 컴파일러 변수·제어 근거`를 확인한다.

- `counter`의 `value` 클로저 저장소와 내부 `increment`의 외부 클로저 ID가 일치한다.
- `choose`에 조건 분기와 반복 역방향 전이가 있다.
- `protected`는 예외 처리 범위와 처리 명령 위치를 제공한다.
- `stream`의 생성·yield 다음은 일반 진행이 아닌 재개 가능 위치다.

대상 코드를 실행하거나 import하지 않는다. 기존 CPython 3.12 런타임에서 `compile`과 `dis`를 사용한다. 명령의 상수 값·원문·원시 오류 메시지는 저장하지 않는다. 심벌명·상대 경로는 저장하므로 민감 파일은 색인에서 제외해야 한다.

`LOCAL_SLOT`과 `CELL_SLOT`은 컴파일러의 저장소 구분이다. 실제 값, 별칭, 함수 대상, 할당 완료 여부를 보장하지 않는다. 전역·클래스 네임스페이스 조회는 런타임에 달라지므로 대상 ID를 확정하지 않는다. 최적화된 comprehension은 같은 저장소를 저장·복원할 수 있다. 전이는 인코딩된 바이트코드 근거이며 실제 실행 이력이 아니다.

CPython 3.12 외에는 `UNSUPPORTED_RUNTIME`으로 표시한다. 컴파일 오류는 `COMPILATION_ERRORS`, 성공 근거는 `COMPILER_BYTECODE`다. 기존 구문/MAY_DEPEND/휴리스틱 위험 경로의 정밀도를 자동 승격하지 않는다. 지원 범위 밖 스택 의미·함수 간 PDG·taint는 추가 구현 대상이다.

최대 원문 2 MB, 코드 범위 500개, 명령/변수/전이/예외/도달 정의/값·제어 의존·입출력 요약 근거 합계 5만, 계산 25만 작업, 기존 프로세스 2분·출력 16 MiB 한도를 적용한다. 원문 해시 및 파일 분석 버전 10이 다르면 재분석한다.

## 명시적 위치·이름 인자 바인딩 (버전10)

`keyword_reordered`는 인자 순번0/1을 본문 매개변수 슬롯1/0에 대응시킨다. `keyword_only`는 위치 전용 first와 이름 전용 second를 구분한다. 둘 다 반환값의 영향 입력은 바깥 left(슬롯0)다. 이름 인자 메타데이터는 컴파일러에서 일시적으로 읽어 매개변수와 대응시킨 뒤 결과에서 제외한다. 선언의 매개변수 이름은 기존 심벌 정보로 유지되지만 호출에 사용된 이름 목록은 따로 저장하지 않는다.

위치/이름 전용 제약·중복·누락·너무 많은 위치 인자·모르는 이름을 검사한다. 잘못된 바인딩은 근거 코드만 표시하고 입출력 연결·값 전파를 만들지 않는다. 생략 기본값·가변 인자/펼침·공유셀·동적 대상은 계속 미지원이다. 모든 인자를 명시하면 기본값 선언이 있는 함수도 대응 가능하다. `test_python_keyword_bindings.py`는96개 인자 순서/반환 슬롯 조합, 한글 이름, 잘못된 호출, 이름/리터럴 미저장과 예산을 검사한다.

아래 버전8/9 절의 이름 인자 미지원 설명은 이전 단계 이력이며 최신 지원 범위는 이 절을 따른다.

## 호출별 본문 반환 데이터 전파 (버전9)

`local_call`은 입력 슬롯0이 inner를 거쳐 반환되는 후보, `local_nested`는 두 단계 호출을 거치는 후보를 보여준다. `local_erased`는 내부에서 상수로 덮어써 입력 영향과 호출 내부 데이터 간선이 없다. 함수 상세의 호출 인자→호출 결과 표는 본문 반환에 실제로 도달하는 입력 슬롯만 연결한다. 서로 다른 호출의 입력 라벨은 공유하지 않는다.

호출 결과 요약과 바깥 반환 요약을 함께 갱신한다. 지원되는 유일 본문 연결만 사용하며, 모호/미지원/외부 호출은 미해석 결과를 유지한다. 본문 내부 미해석 값도 원래 ID로 전달된다. `OPAQUE_CALL_RESULT`는 원시 함수 내부 값 그래프의 ID 종류이며, 최종 해석 상태는 호출 결과 요약을 따른다. 조건 의존·종료·예외·부수효과·힙/별칭·실제 함수 객체 변경은 이 데이터 요약으로 확정하지 않는다. 빈 영향/미해석 목록은 안전성 증명이 아니다.

`test_python_call_summaries.py`는 전달·덮어쓰기·인자 재배치·다단계·호출 격리·외부 값 전파·미사용 외부 호출·미지원/예산과16개 프로그램/256분기 조합의 독립 정답을 검사한다. 프로세스별 해시 시드3종에서 같은 결과를 확인한다.

## 지역 함수 객체 → 본문·입출력 위치 (버전8)

`local_call`의 inner 생성→copied 별칭→호출 경로로 유일한 지역 함수 본문 후보를 연결한다. CALL_TARGET까지 지역 읽기/쓰기와 함수 생성의 코드 객체 입력만 따라가며 연산·컨테이너·속성·외부 조회는 함수 정체성을 전달하지 않는다. `local_choice`처럼 외부 후보가 섞이면 AMBIGUOUS이고 입출력 위치는 연결하지 않는다. 이름이 같다는 이유로 전역 함수를 연결하지 않는다.

유일한 본문에서 값 근거를 제공하고, 모든 매개변수가 위치 인자를 받으며 인자 수가 정확히 맞을 때만 호출 인자 ID→매개변수 ID, 본문 반환 ID→이번 호출 결과 ID를 기록한다. 기본값을 사용하는 생략 호출·이름/가변 인자·공유셀·데코레이터와 미지원 본문은 제외한다. 명시적으로 모든 위치 인자를 제공한 함수는 기본값 선언이 있어도 연결할 수 있다. 함수 객체/코드 변경·실제 호출·경로 만족성은 확정하지 않는다. 버전8은 위치 연결만 제공했고, 버전9에서 위 호출별 데이터 요약을 추가했다.

`test_python_local_calls.py`는 별칭·덮어쓰기·다중/외부 후보·호출별 격리·정적 주석·미지원/예산과 32프로그램/1024분기 조합의 독립 함수 정체성 정답을 검사한다.

## 입력 → 반환·호출 요약

`summarized`의 반환 데이터 입력은 left/right(슬롯1/2)이며 조건 flag(0)는 별도 제어 근거다. `cleared`는 입력을 덮어써 반환 영향 입력이 없다. `publish`는 target(1)과 인자들의 value(0) 영향, 호출 결과의 미해석 ID를 구분한다. 호출 인자를 결과에 추측 연결하지 않는다.

입력 번호는 CPython 슬롯 순서(위치 전용·일반 위치·이름 전용·가변 위치·가변 이름)다. 소스 선언 순서나 호출 인자 바인딩이 아니다. 가변 인자는 컨테이너 슬롯으로 유지한다. 기본값과 이름 인자의 이름은 기록하지 않는다. 속성·반복/분해·외부 조회·미할당·호출 결과는 미해석 ID를 전파한다. 미지원 값 모델은 요약도 UNAVAILABLE이다. 경로 조건·연산자/프로토콜의 사용자 코드 효과·실제 함수 대상·함수 간 반환은 해소하지 않는다. 목록이 비어도 안전성 판정이 아니다.

정답집: `test_python_value_summary.py`는 32개 덮어쓰기 프로그램의 1024개 분기 조합, 매개변수 종류·호출별 격리·비밀 리터럴 제외·예산/미지원 경계를 검사한다. 대상 프로그램은 실행하지 않는다.

## 할당 → 읽기

함수 상세의 `할당 → 읽기 도달 정의`에서 입력 매개변수·할당·삭제/초기 미할당 후보가 어느 읽기에 도달하는지 확인한다. `choose`는 반복 중 이전 입력/할당 후보, `maybe`는 분기에 따른 미할당 후보를 보여준다. 이는 슬롯에 기록한 위치의 관계이며 우변 값이나 힙/별칭/함수 간 값 전파가 아니다.

`LOCAL_SLOT_DEFINITIONS`는 모델 범위의 로컬 슬롯 분석이다. 예외 범위가 있으면 명령 전후 상태의 합집합을 처리 후보에 보내며 `PARTIAL_SLOT_DEFINITIONS`로 표시한다. 재개 후보와 공유 클로저 셀 제외도 부분 상태의 이유다. 스택으로 저장·복원하는 comprehension과 동적 모듈/클래스 범위는 `UNAVAILABLE`이다. 미할당 후보는 실제 오류 발생 증명이 아니며, 후보가 없다고 안전한 것도 아니다. 디버거/추적기 등이 외부에서 프레임 변수를 바꾸는 동작은 모델 밖이다.

## 연산 → 할당·반환·호출 인자

`publish`는 입력 `value`가 덧셈·`adjusted` 할당·읽기를 거쳐 첫 호출 인자로 전달되는 근거를 보여준다. 두 번째 인자는 이름 인자 여부와 순번만 표시한다. `target`의 실제 함수는 확정하지 않으며 호출 반환값은 미해석 경계다. 입력→호출 인자와 호출 결과→반환은 연결하지만 입력→호출 결과는 추측하지 않는다.

`choose`는 while 반복의 값 후보를 보여준다. 후보 합집합은 실행 가능한 경로만 골라내지 않으며 연산자 오버로드·힙/별칭·외부 프레임 변경은 모델 밖이다. 예외/생성기/공유셀 및 미지원 명령이 있으면 값 그래프를 비우고 `UNAVAILABLE` 사유를 표시한다. 기존 슬롯 근거는 계속 확인할 수 있다.

## 반복·수신 객체

`walk`는 `items`→반복자→반복 요소→`value` 할당/읽기→호출 인자를 보여준다. `receiver`는 `send` 속성 조회와 수신 객체 후보에 별도로 연결된다. 반복 종료 시 `END_FOR`를 건너뛴 전이가 표시된다. `receiver.result` 조회는 미해석 속성 프로토콜이며 실제 반환값/별칭은 확정하지 않는다.

반복·속성 조회·분해는 사용자 코드를 호출할 수 있다. 메서드 스택을 정규화한 수신 객체는 실제 `self` 확정이 아니다. 가변 개수 분해/인자 펼침, 예외 스택, 생성기·공유셀·comprehension 복원은 추가 구현 대상이다. 정답집의 명령 추적은 테스트 모듈 안의 고정 fixture만 실행하며 사용자 저장소 대상은 실행하지 않는다.

정답집: `src/SMSR.App/GraphRuntime/test_python_compiler.py`를 설치된 graph-runtime Python으로 실행한다.

## 조건 → 명령 제어 의존

`decision` 상세에서 TRUE/FALSE별 반환 명령 연결을 확인한다. `choose`는 반복 조건의 제어 의존, `walk`는 반복 소진/다음 요소를 구분한다. `endless`는 종료에 도달하지 못하는 영역, `protected`는 예외, `stream`은 중단 때문에 이 계산이 불가한 사유를 표시한다. 다른 변수·값 근거의 지원 판정과는 별개다.

명령 위치와 소스 위치를 함께 표시한다. CPython은 짧은 반환 구간을 각 분기로 복제할 수 있으므로 같은 소스 줄이라도 다른 명령의 실행 조건은 다르다. 후지배는 정상 전이에서 종료까지 가는 경로를 기준으로 계산하며 -1은 반환/명시적 raise의 합성 종료다. 암묵적 예외·경로 조건·무한 실행 여부를 증명하지 않으며 안전성 판정이 아니다. 조건부 반복이 종료 가능한 것과 실제로 반드시 종료하는 것은 다르다.
